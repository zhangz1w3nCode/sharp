Tauri v2 窗口 vibrancy
摘要
macOS 下窗口毛玻璃的实现要点与 NSVisualEffectView 兼容配置。
内容

实现

通过 windowEffects 配置 vibrancy,需 NSVisualEffectView 兼容。相关见 macOS HIG 与 Wikilink 解析。

// tauri.conf.json — windowEffects
"windowEffects": {
  "effects": ["sidebar"],
  "state": "active"
}

要点

  • 配置 NSVisualEffectView + NSHUDWindowMaterial
  • 断链如 未知文档 显示虚线,点击可创建
  • 字体回退见 SF Pro 字体回退栈
